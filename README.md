# Telegram Mini App — «Признание»

Готовая музыкальная открытка для Telegram Mini App.

## Внутри
- `index.html` — весь интерфейс и логика плеера
- `assets/cover.png` — обложка
- `assets/song.mp3` — трек
- `assets/lyrics.lrc` — синхронизированный текст

## Как запустить локально
В папке проекта:

```bash
python3 -m http.server 8080
```

Открой `http://localhost:8080` в браузере.

## Как подключить к Telegram
1. Размести содержимое этой папки на HTTPS-хостинге.
2. В @BotFather создай/выбери бота.
3. Создай Mini App и укажи URL страницы `index.html`.
4. Добавь кнопку запуска Mini App в меню бота или в сообщение.

Приложение уже вызывает Telegram WebApp API, расширяет окно и подстраивает фон под открытку.
